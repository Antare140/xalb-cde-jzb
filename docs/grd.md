# 应用名称：鲨鱼小账本
# 品类：其他 - 工具类应用（收支管理 / 轻模拟经营式数据养成）
# 标签：记账 收支管理 预算 图表统计 多账本

## 一句话介绍
参考鲨鱼记账的极简体验，3 秒记一笔，多账本 + 分类自定义 + 预算预警 + 可视化图表，把每一笔钱都管明白的纯前端 H5 记账本。

## 应用背景
用户是一个想开始理财但被复杂财务软件劝退的普通人。本应用做「减法」：去掉理财广告与冗余流程，只保留记账本质——快速录入、清晰回看、直观分析、预算约束。所有数据保存在浏览器本地（localStorage），解压即用、无需登录、无需网络。

## 目标平台
移动端优先（竖屏 720×1440，Letterbox 适配），同时兼容 PC 浏览器（画面居中显示）。

## 目标上线时间
单版本一次性交付，无长期运营计划。

## 2. 目标人群

### 核心用户画像
- **主要人群**：初次记账的学生与年轻上班族（占比约 60%）——怕麻烦，需要极速录入和一眼看懂的图表。
- **次要人群**：有记账习惯的家庭开支管理者（占比约 30%）——需要多账本区分场景（日常/旅行/装修）、预算控制。
- **扩展人群**：临时项目记账用户（占比约 10%）——如一次旅行、一场装修的专项账目。

### 人群特征分析
- **年龄段**：18-40 岁为主。
- **使用经验**：新手到休闲级，不接受复杂的复式记账概念。
- **使用习惯**：单次使用 10-40 秒（记一笔）；每周有 1-2 次 2-5 分钟的回看与图表分析。
- **付费能力**：本作为纯免费工具，无内购。

## 3. 核心玩法（核心使用循环）

### 核心循环
1. 用户点击首页大号「＋ 记一笔」按钮
2. 系统弹出记账面板：选类型（支出/收入）→ 点分类图标 → 数字键盘输入金额 → 可选填备注/日期/账户
3. 点「保存」→ 顶部飘字 `-¥28.00 餐饮` + 金币粒子反馈 + 预算进度条即时增长
4. 账单列表新增一条、月度汇总与资产余额同步刷新
5. 用户获得「记录完整度」正反馈（连续记账天数 + 本月已记笔数），激发次日继续记账

### 主要机制

#### 机制 1：极速记一笔
- **描述**：单页面完成一笔记录，默认带入「今天 + 上次使用的分类 + 上次使用的账户 + 当前账本」，最少 3 次点击（分类 → 金额 → 保存）即可完成。
- **触发条件**：点击任意页面底部中央的「＋」按钮，或账单页日历某日的快捷「＋」。
- **效果**：新增一条流水，写入 localStorage，联动刷新汇总、预算、资产、图表。

#### 机制 2：多账本隔离
- **描述**：支持创建多个账本（默认「日常账本」，可加旅行/装修/生意/人情等）。账单、图表、预算均按当前账本过滤；资产账户全局共享。
- **触发条件**：首页顶部账本名称点击切换，或在「我的-账本管理」中新增/重命名/删除。
- **效果**：切换后所有页面数据立即按新账本重算；删除账本时其流水一并删除（需二次确认）。

#### 机制 3：分类体系自定义
- **描述**：内置支出 16 类 / 收入 6 类（emoji 图标 + 名称），支持新增、重命名、换 emoji、删除、拖拽调序（长按上下移动按钮实现）。
- **触发条件**：「我的-分类管理」。
- **效果**：分类变更即时反映在记账面板与图表分类中；删除已有流水的分类时，历史流水归入「其他」。

#### 机制 4：月度预算与超支预警
- **描述**：可为当前账本设置「月总预算」，并可为单个支出分类设置「分类预算」。首页展示预算进度条与剩余可用金额、日均可用建议。
- **触发条件**：保存任意支出后自动重算。
- **效果**：
  - 使用率 < 70%：进度条绿色，文案「节奏不错」
  - 70%~99%：黄色，文案「预算即将用完」+ 顶部黄条提醒
  - ≥ 100%：红色 + 轻震动 + 提示「本月已超支 ¥X」

#### 机制 5：可视化分析
- **描述**：图表页三块内容——分类占比饼图（可切支出/收入）、近 6 个月收支趋势柱状+折线图、支出 TOP5 排行榜（带占比条）。
- **触发条件**：进入图表页或切换月份/维度。
- **效果**：点击饼图扇区高亮并显示该分类金额、占比、笔数，点击可下钻到该分类流水列表。

#### 机制 6：资产账户管理
- **描述**：管理现金、银行卡、支付宝、微信钱包等账户及其余额；记账时选择账户，支出减余额、收入加余额；支持「转账」类型在两账户间移动金额（不计入收支统计）。
- **触发条件**：资产页新增/编辑账户；记账时选择账户。
- **效果**：资产页展示总资产 = 各账户余额之和，并列出各账户占比。

#### 机制 7：记账习惯激励
- **描述**：统计「连续记账天数」「本月记账笔数」；连续 3/7/30 天达成时弹出祝贺弹窗 + 粒子庆祝。
- **触发条件**：每日首次成功保存流水时判定。
- **效果**：首页徽章展示，形成正反馈。

#### 机制 8：数据导出与备份
- **描述**：支持将当前账本或全部流水导出为 CSV（Excel 可打开）与 JSON 备份文件；支持导入 JSON 恢复。
- **触发条件**：「我的-数据管理」。
- **效果**：浏览器直接下载文件；导入时校验格式并二次确认覆盖。

### 操作方式
- **移动端**：全触摸操作。底部 5 键 Tab 栏（账单/图表/＋/资产/我的）；自绘数字键盘录入金额；账单列表左滑显示「编辑 / 删除」按钮；日历左右滑动切换月份。
- **PC 端**：鼠标点击等效所有触摸操作；额外支持物理键盘 0-9 `.` 输入金额、Backspace 删除、Enter 保存、Esc 关闭弹窗；鼠标滚轮滚动列表。
- 所有交互同时监听 `pointerdown/pointerup`（或 mouse + touch 双绑定），保证两端一致。

### 目标与结算条件
- **达成目标（正向结果）**：本月结束时未超预算，且记账笔数 ≥ 15 笔 → 月结算卡片评级 A，文案「本月控得很稳」。
- **失败提示（负向结果）**：本月支出超预算 → 月结算卡片评级 C，文案「超支 ¥X，下月把预算收紧一点」。
- **结算反馈**：进入新的自然月后首次打开应用，弹出「上月月报卡片」：总收入、总支出、结余、最大单笔、支出最多分类、预算达成评级（A/B/C），带庆祝或提醒音效与粒子，可一键关闭或查看详情。

### 乐趣来源
- **掌控感**：预算进度条与剩余日均可用金额，把抽象消费变成可控数字。
- **收集/养成**：连续记账天数徽章、月报评级。
- **洞察快感**：饼图与 TOP5 排行「原来钱花在这里」的揭示时刻。
- **即时反馈**：飘字、粒子、进度条动画让每次记账都有回响。

### 难度曲线（上手曲线）
- **首次打开**：3 步引导蒙层（指向「＋」按钮 → 分类区 → 底部 Tab），并预置 1 条示例流水（可一键清除）。
- **第 1 周**：仅需掌握记一笔与看账单。
- **第 2 周起**：引导设置预算（首页预算卡片未设置时显示「点我设置本月预算」）。
- **进阶**：多账本、分类自定义、资产与转账、数据导出。

### 计算公式
- 月支出合计 = Σ(当前账本 且 类型=支出 且 月份匹配 的 amount)
- 月结余 = 月收入合计 − 月支出合计
- 预算使用率 = 月支出合计 ÷ 月总预算（预算为 0 或未设置时不显示进度条）
- 剩余日均可用 = max(0, (月总预算 − 月支出合计)) ÷ 本月剩余天数（含今日）
- 总资产 = Σ(各账户 balance)
- 分类占比 = 该分类金额 ÷ 该月同类型总额 × 100%（分母为 0 时显示空状态）
- 连续记账天数：若上次记账日期为「昨天」则 +1，为「今天」则不变，否则重置为 1

## 6. 系统设计

### 系统 1：流水记录系统
- **功能描述**：增删改查一笔收支/转账记录。
- **核心功能**：
  - 新增：类型、金额、分类、账户、日期、备注
  - 编辑：列表左滑或点击流水进入编辑，复用记账面板
  - 删除：左滑删除 + 二次确认，删除后回滚账户余额
  - 转账：从账户 A 减、账户 B 加，不计入收支与图表
- **交互**：写入后触发汇总、预算、资产、图表、习惯统计全链路刷新。

### 系统 2：账本系统
- **功能描述**：多场景数据隔离。
- **核心功能**：新增/重命名/删除账本、切换当前账本、每账本独立预算。
- **交互**：默认账本不可删除；删除账本连带删除其流水（二次确认）。

### 系统 3：分类系统
- **功能描述**：自定义收支分类。
- **核心功能**：新增（选 emoji + 命名）、重命名、换图标、上/下移排序、删除（流水归入「其他」）、设置分类预算。

### 系统 4：预算系统
- **功能描述**：月度总预算 + 分类预算，实时进度与预警。
- **核心功能**：设置/修改/取消预算；进度条三色态；超支提醒；剩余日均可用建议。

### 系统 5：统计图表系统
- **功能描述**：Canvas 绘制的分类占比、收支趋势、支出排行。
- **核心功能**：月份切换、类型切换、扇区点击下钻、趋势图柱形点击查看该月汇总。

### 系统 6：资产系统
- **功能描述**：账户余额与总资产管理。
- **核心功能**：新增/编辑/删除账户、余额校正、隐私模式隐藏金额、账户占比展示。

### 系统 7：习惯激励系统
- **功能描述**：连续记账天数、本月笔数、里程碑庆祝、跨月月报。
- **核心功能**：streak 计算、里程碑弹窗、上月月报卡片与评级。

### 系统 8：数据持久化与导入导出系统
- **功能描述**：localStorage 读写 + CSV/JSON 导出 + JSON 导入。
- **核心功能**：每次变更即时保存（防抖 200ms）；启动读取并做结构校验与版本迁移；导出使用 Blob 下载；导入前二次确认并校验字段。

### 创新点
- 首页把「预算进度 + 剩余日均可用 + 连续记账徽章」三合一，让记账像养成任务。
- 跨月自动月报卡片，把工具型应用做出「结算感」。
- 纯前端零依赖，解压双击即用，数据不出本机。

## 7. 关卡设计（功能层级与引导节奏）

### 层级结构
- **第一层（核心，首次打开即可用）**：记一笔、账单时间轴、月度汇总
- **第二层（第一次回看时暴露）**：日历视图、图表页、月份切换
- **第三层（进阶）**：预算设置、多账本、分类自定义
- **第四层（高级）**：资产账户与转账、隐私模式、导出导入、清空数据

### 节奏设计
- **前期（首次使用 0-1 分钟）**：3 步引导蒙层 → 引导完成第一笔记录 → 保存成功庆祝。
- **中期（累积 5 笔后）**：首页出现「设置本月预算」引导卡；图表页数据可用。
- **后期（累积 20 笔或跨月）**：弹出上月月报；提示可创建第二个账本或导出备份。

### 教学设计
- **新手引导**：首次启动蒙层 3 步（＋按钮 / 分类区 / 底部 Tab），可跳过，状态存 `meta.guideDone`。
- **上下文提示**：空列表、未设预算、无账户余额等场景各自带一句引导文案与按钮。
- **示例数据**：首次启动预置 1 条「🍚 餐饮 -¥28.00 午餐」示例流水，并在其旁提供「清除示例」按钮。

## 8. 边界与异常处理

- **数值边界**：
  - 金额为空、0、纯小数点或超过 `MAX_AMOUNT` 时禁止保存并飘红提示；输入自动限制两位小数、禁止多个小数点、禁止前导多个 0。
  - 负数不通过键盘产生；余额允许为负（信用卡场景）并以红色显示。
  - 预算为 0 视为未设置，不做除法；所有占比计算分母为 0 时返回 0 并展示空状态。
  - 大额金额显示自动缩写（≥1 亿显示「x.xx亿」）防止溢出布局。
- **交互边界**：
  - 保存按钮点击后立即置灰 300ms 防连点；弹窗只允许单层叠加，打开新弹窗前关闭旧弹窗。
  - 画面外/空白区点击关闭面板；面板打开时禁止背景滚动。
  - 输入框失焦自动 trim；备注超长自动截断到 30 字。
  - 分类/账本/账户数量达上限时禁用新增按钮并提示原因。
- **状态边界**：
  - 页面切换、面板开合状态机唯一，禁止并发过渡动画。
  - 页面失焦（`visibilitychange`）暂停 Canvas 动画帧，回到前台恢复。
  - 跨月/跨天回到前台时重算「今日/本月」上下文与月报判定。
  - 编辑中的流水被另一路径删除时，保存失败并提示「该记录已不存在」。
- **资源兜底**：
  - 图片（顶部背景、空状态插画、奖章）加载失败时降级为 Canvas/CSS 绘制的纯色渐变块与 emoji 占位，不出现裂图。
  - 音效加载失败或浏览器禁止自动播放时静默跳过，不阻塞保存流程；首次用户交互后再解锁音频。
- **存储异常**：
  - localStorage 不可用（隐私模式/超配额）时降级为内存模式，顶部常驻黄条提示「当前无法保存数据，请导出备份」。
  - 读取时 JSON 解析失败或结构校验不通过 → 自动备份原始字符串到 `shark_ledger_backup`，以默认数据启动并提示。
  - 写入抛 `QuotaExceededError` → 提示导出并清理旧数据，不静默丢数据。
  - 流水超过 `MAX_RECORDS` 时提示导出归档，仍允许继续记录。
  - 导入 JSON 字段缺失/类型错误时整体拒绝并提示具体原因，不做部分导入。

## 10. 最终方案确认（阶段 3 结论）

### 10.1 范围确认（已确定采纳）
| 项目 | 结论 |
|---|---|
| 游戏/应用品类 | 工具类应用（收支管理），无战斗无失败态，以「数据养成 + 结算感」提供正反馈 |
| 目标人群 | 初次记账的学生与年轻上班族为主 |
| 核心循环 | 点「＋」→ 选分类 → 输金额 → 保存 → 飘字/粒子/预算条即时反馈 |
| 长期目标 | 连续记账天数徽章 + 跨月月报 A/B/C 评级 |
| 单次体验时长 | 记一笔 10-40 秒；回看分析 2-5 分钟 |
| 上手难度 | 首启 3 步引导蒙层 + 1 条示例流水，零学习成本 |
| 数据存储 | 纯本地 localStorage，无登录无网络，支持 CSV/JSON 导出与 JSON 导入 |

### 10.2 明确不做（本版边界）
- **不做记账提醒/定时通知**：纯网页环境无法在关闭页面后推送，改为首页「今天还没记账」轻提示条替代。
- **不做账单拍照存小票**：涉及相机权限与图片存储配额，localStorage 易超限；改为备注文字（30 字内）记录。
- **不做周预算/年预算**：本版只做「月总预算 + 分类预算」两级，避免概念膨胀。
- **不做云同步、多人协作、账单分期、汇率与多币种**：统一人民币 `¥`。
- **不做真实银行/支付平台对接**：账户余额由用户手工维护与校正。

### 10.3 功能优先级（开发顺序）
1. **P0 必须**：数据层与持久化、记账面板（含数字键盘）、账单时间轴、月度汇总、分类体系、底部 Tab 导航、编辑与删除。
2. **P1 重要**：日历视图、图表页（环形图 / 趋势图 / TOP5）、预算设置与三色预警、资产账户与转账。
3. **P2 增强**：多账本管理、分类自定义与排序、连续记账里程碑、跨月月报、隐私模式、CSV/JSON 导出导入、新手引导蒙层。

- **需生成（已全部完成）**：3 张图片（`assets/images/header_bg.png` 720×420、`assets/images/empty_shark_transparent.png` 400×400 透明底、`assets/images/medal_transparent.png` 300×300 透明底）+ 2 个音效（`assets/audio/success.mp3`、`assets/audio/fail.mp3`）。

- **全部图片均有降级兜底**：加载失败时头图降级为 CSS 渐变、空状态与奖章降级为大号 emoji（🦈 / 🏅），不出现裂图。
