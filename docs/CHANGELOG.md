# 更新日志

## v1.0.0 - 2026-08-26

首个可运行版本，按 `docs/grd.md` 完成 P0/P1/P2 全部功能。

### 新增

**工程与基础**
- 建立零依赖前端工程：`index.html` + `css/style.css` + `js/{config,utils,loader,input,store,fx,charts,ui,game}.js`
- 720×1440 竖屏设计分辨率，等比 Letterbox 适配，PC 居中显示，移动端不拉伸
- 资源预加载页（进度条），图片加载失败降级 emoji/CSS 渐变，音效失败静默跳过
- 全部数值收敛到 `js/config.js`，逻辑中无硬编码关键数值

**P0 核心记账**
- 数据层 `store.js`：localStorage 持久化（200ms 防抖）、结构校验与迁移、损坏数据自动备份
- 记账面板：支出/收入/转账三段切换、分类网格、自绘 4×4 数字键盘、日期/账户/备注选择
- 默认带入上次分类、上次账户与今天日期，最少 3 次点击完成一笔
- 账单时间轴：按日分组、当日收支小计、分页加载（每次 30 条）
- 月度汇总头图：本月支出/收入/结余，月份左右切换
- 内置支出 16 类 + 收入 6 类（emoji 图标），默认 4 个资产账户
- 流水编辑与删除（二次确认），删除自动回滚账户余额
- 首次启动预置 1 条示例流水，可一键清除

**P1 分析与资产**
- 日历视图：月历格显示每日支出/收入，今日高亮，点击查看当日流水，左右滑动切月
- 图表页：Canvas 环形图（点击扇区下钻到分类流水）、近 6 月支出柱+收入折线趋势图、支出 TOP5 排行条
- 预算系统：月总预算设置，进度条绿(<70%)/黄(70%~99%)/红(≥100%) 三色态，剩余金额与日均可用建议，超支震动+警示音
- 资产页：总资产卡、账户列表与占比、账户增删改、转账（不计入收支统计）

**P2 增强**
- 多账本：顶部快捷切换 + 我的页账本管理（新建/改名/删除，删除连带流水并回滚余额）
- 分类自定义：新增、改名、换 emoji、上下移排序、删除（历史流水归入「其他」）、分类月预算
- 连续记账天数统计，3/7/30 天里程碑弹窗（奖章 + 粒子 + 音效）
- 跨月自动弹出上月月报卡片，A/B/C 评级，支持我的页手动回看
- 隐私模式：一键把所有金额显示为 `****`
- 数据管理：导出 CSV（带 BOM，Excel 可直接打开）、导出 JSON 备份、导入 JSON 恢复（字段校验，不做部分导入）、清空数据
- 新手引导蒙层 3 步（＋按钮 / 底部 Tab / 预算卡片），可跳过、可重看
- 音效开关

**反馈体验**
- 保存成功：大号飘字（如 `-¥28.00 餐饮`）+ 保存键位置金币粒子爆发 + 提示音
- Toast 提示、屏幕震动、闪白、进度条与面板过渡动画

### 边界与异常处理
- 金额：空/0/超上限拒绝保存并飘红提示，限制两位小数、禁止多个小数点与前导多 0，≥1 亿自动缩写显示
- 交互：保存键 300ms 防连点、弹窗单层叠加、点遮罩关闭、转出转入账户不可相同
- 状态：页面失焦暂停 Canvas 动画帧，回到前台重算今日/本月与月报判定
- 存储：localStorage 不可用降级内存模式并常驻黄条提示；配额超限提示导出清理；数据损坏自动备份后以默认数据启动
- 账户余额允许为负（信用卡场景）并标红；有流水的账户禁止删除；至少保留一个账本/分类/账户
